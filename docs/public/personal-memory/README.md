# Personal Memory

Apple Watch で一日の出来事を録音し、iPhone を経由して Mac に渡し、**Mac の中のローカル AI** で「読み返せる一日の記憶」にまとめるアプリです。

- **利用料はかかりません。** 文字起こしは Mac の中の音声認識(speech.cpp)、清書と要約は Mac のローカルモデル(Ollama)で行います。クラウドの AI や API キーは使いません。
- **日本語に対応しています。** 文字起こしは日本語の認識モデル parakeet-tdt_ctc-0.6b-ja を使い、Haas-ja-v1.0 を二つ目の意見にします。どちらも無い Mac では macOS の日本語の認識を使います(下の「必要なもの」)。
- **録音は、あなたの端末と、あなたが選んだ共有フォルダにだけ置かれます。** このアプリのサーバーはありません。共有フォルダに iCloud Drive を選んだ場合は、録音が Apple の iCloud を通ります。

## 構成

| 場所 | 中身 |
|---|---|
| `WatchMemory/` | Watch アプリ。録音、聴き直し、iPhone への送信 |
| `PersonalMemory/` | iPhone アプリ。Watch からの受信、聴き直し、Mac への受け渡し |
| `SharedAudio/` | iPhone と Watch で共通の録音一覧と再生 |
| `SessionDomain/` | 録音の区切りの記録と、受け渡し用のファイル形式(`.pmchunk`) |
| `CalendarAssistant/` | Mac アプリ「Personal Memory Calendar」。一日ごとの文字起こし、カレンダーとメモの候補、一日の記憶 |

## できること

- **Watch で録音**: 約 10 分ごとに区切って保存します。録音中も文字盤に戻れます。タイマーなどで中断されても、停止ボタンを押すまで自動で再開します。iPhone が同じ中身で保存したことを確かめてから、Watch から消します。停止ボタンを押さずにアプリが終わったときは、開き直すと録音を再開します。
- **iPhone から Mac へ**: iPhone と Mac で同じフォルダ(例: iCloud Drive の「Personal Memory」)を一度選ぶと、Watch から届いた録音を iPhone がそのフォルダに置き、Mac のアプリが取り込みます。1 つの録音は 1 つの `.pmchunk` ファイル(情報と音声をまとめ、SHA-256 で検査)なので、同期の途中の半端な状態を取り込みません。同じ Wi‑Fi なら 6 桁の番号でつないで直接送ることもできます。
- **一日ごとにまとめて表示**: Watch は約 10 分ごとに区切って保存しますが、iPhone・Watch・Mac のどれでも録音は「日」単位で並びます。iPhone と Watch では日を押すと、その日の録音を頭から続けて再生します。Mac では「この日を再生」で、録音の無い時間を詰めて1本の録音として再生し、好きな位置へ動かせます。今聞いている音を録った時刻も出ます。
- **Mac で一日をまとめて文字起こし**: 「日ごと」の画面で日付のボタンを押し、「この日を文字起こし」を押すと、その日の録音すべてを Mac の中で文字起こしします。途中で止めても、もう一度押すと続きから行います。無音の部分は飛ばします。声の違いを聞き分け、行の頭に「話者1:」のように付けます(番号は10分の区切りごと)。書き起こしは区切りごとに手で直せ、直した区切りは「書き起こしをやり直す」で上書きしません。ローカル AI が書き起こしを読める文に整えた「清書」も作れます。
- **カレンダーとメモに分けて提案**: 「項目に分けて提案」を押すと、ローカル AI がその日の文字起こしを読み、「カレンダーに入れる予定」と「メモに残すこと」の候補を作ります。候補には根拠になった発言を添え、文字起こしに無い引用は捨てます。日時がはっきりしない予定は空欄のままにします。保存先(カレンダー/メモ)、件名、内容、日時は直せて、確認した 1 件ずつだけ保存します。「不要」にした候補は、提案し直しても戻りません。
- **1つのファイルに書き出す**: 「書き出す…」で、一日分または開始と終了の時刻を指定した範囲を、MP3・WAV・M4A の1つのファイルにします(録音の無い時間は詰めます。MP3 には Homebrew の lame が要ります)。
- **音声の削除を選べる**: 「この日の音声を削除…」で、Mac と共有フォルダの音声をゴミ箱に移し、iPhone のアプリにもコピーを消すよう伝えます。共有フォルダを設定していないときは、iPhone のコピーは残ります(確認の文もそう伝えます)。文字起こしと候補は残ります。
- **一日の記憶**: 別の画面で、その日の出来事を時刻順の短い記憶にまとめることもできます。

## 必要なもの

- Xcode 26 以降、iOS 17 / watchOS 10 / macOS 14 以降
- Mac で AI を使う場合: [Ollama](https://ollama.com) と日本語に強いモデル(既定は Qwen3.8-27B の Q4_K_M。アプリの「ローカルAIの設定」で変えられます)
- Mac で正確に文字起こしする場合: [speech.cpp](https://github.com/nyosegawa/speech.cpp) 0.10.0 を `~/Tools/speech.cpp-0.10.0/` に置き、`speech pull parakeet-tdt_ctc-0.6b-ja`、`speech pull haas-ja-v1.0`、`speech pull nemotron-3-diarization` でモデルを取得します(話し声の検出には Homebrew の whisper.cpp と Silero VAD のモデル `~/Models/whisper/ggml-silero-v5.1.2.bin`)。無ければ macOS の認識を使います
- MP3 で書き出す場合: Homebrew の `lame`

## ビルド

```sh
# 録音・受け渡しの部品の試験(Mac 上で動きます)
swift test

# Mac アプリ(Builds/ に .app を作ります)
cd CalendarAssistant && zsh build-app.sh
```

iPhone と Watch のアプリは `PersonalMemory.xcodeproj` を Xcode で開き、各ターゲットの Signing で自分の開発チームを選んでから実機に入れてください(バンドル ID も自分のものに変えてください)。Watch の裏での録音には実機が必要です。

## 作り方について

このアプリの部品の一部は、ローカルモデルで Swift のコードを作るアプリ [Local Factory for Mac](https://github.com/jc58fwv8ds-hash/local-factory-for-mac) で作りました。人が目的・試験・隠し試験を書き、Local Factory が実装し、人が検査して取り込んでいます(人が直した箇所は記録しています)。
