# 見本の課題集(sample-suite)

Local Factory for Mac の計測の仕組みを試すための、公開用の小さな課題集です(3 件)。
非公開の計測用の課題集とは別に作ったもので、隠しテストも含めて公開しています。

| 番号 | 種類 | 依頼 |
|---|---|---|
| s-01 | 不具合の修正 | 「5,000 円以上は送料無料」のはずが、ちょうど 5,000 円で送料がかかる |
| s-02 | 機能の追加(2 ファイル) | 完了済みを除いた残り件数を、要約に「残り N 件」と表示する |
| s-03 | 振る舞いの変更 | 時間帯ごとのあいさつの区切りを変える(境界に注意) |

各課題は 1 つの JSON ファイルで、依頼文・変更前のパッケージ・見えるテスト・隠しテスト・正しい変更の例・
もっともらしい誤った変更の例を持ちます。作る役(AI)には依頼文と変更前のコードだけが見え、
テストの中身・正しい変更の例・隠しテストは見えません。

- 課題の検証(変更前は失敗、正しい変更は合格、誤った変更は隠しテストで失敗):
  `python3 eval/sample-suite/validate_suite.py --dynamic --candidate .`
- 計測(既定は Backburner。Ollama のモデルなら `--model <名前>`):
  `python3 eval/b5-runner/run_suite.py --candidate . --suite sample-suite --out work/sample-run`
- 偽成功 = 見えるテストは通ったが、隠しテストで失敗したもの。
